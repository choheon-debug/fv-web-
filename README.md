# 미래가치 계산기 (웹앱)

매달 넣는 돈이 월 복리로 얼마가 되는지 계산하는 웹앱입니다. 아이폰·안드로이드 모두 인터넷 주소로 열고 홈 화면에 추가해 앱처럼 씁니다.

- 입력: 매월 불입금액, 월 복리 이자율, 투자 기간(개월), 초기 투자금
- 결과: 예상 미래가치(한글 금액 함께), 총 원금·총 이자, 월 이자율의 연 환산, 연도별 원금·이자 막대그래프와 표
- 목표 분석: 목표 금액을 넣으면 지금 조건으로 걸리는 기간, 기간 안에 필요한 월 납입액, 필요한 이자율을 계산
- 계산: 매달 말 납입, 이자는 달마다 원금에 더함. FV = P(1+r)^n + M((1+r)^n − 1)/r. 세금·수수료 제외
- 입력값은 휴대폰에만 저장, 인터넷 없이도 열림
